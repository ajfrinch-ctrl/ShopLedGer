**স্টক রেজিস্টার (ShopLedGer)** — গবাদি পশুর খাদ্য সরবরাহসহ যে কোনো খুচরা ও পাইকারি প্রতিষ্ঠানের জন্য তৈরি সম্পূর্ণ বাংলা, আধুনিক ও মোবাইল-ফার্সট ব্যবসায়িক হিসাব ও ইনভেন্টরি ম্যানেজমেন্ট PWA অ্যাপ।

বিক্রি, বাকি আদায়, ক্যাশ মেমো, স্টক নিয়ন্ত্রণ, দৈনিক খরচ, লাভ-ক্ষতি এবং স্বয়ংক্রিয় বাংলা PDF রিপোর্ট — সব কিছু এক ছাতার নিচে। এটি সম্পূর্ণ অফলাইন-ফার্স্ট; অর্থাৎ ইন্টারনেট সংযোগ ছাড়াও নিরবচ্ছিন্নভাবে ব্যবহার করা যায়।

## ✨ মূল বৈশিষ্ঠ্যসমূহ

### ১. দ্রুত বিক্রি ও স্মার্ট ক্যাশ মেমো (POS & Billing)

- **ইনস্ট্যান্ট সেলস কাউন্টার:** বারকোড বা কাস্টমার সার্চ, ড্রপডাউন থেকে পণ্য নির্বাচন ও দ্রুত হিসাব।
- **নগদ ও বাকি সমন্বয়:** প্রতিটি চালানে নগদ জমা, ডিসকাউন্ট ও স্বয়ংক্রিয় বাকি হিসাব।
- **A5 ক্যাশ মেমো PDF (সোজা/প্রচলিত ফরম্যাট):** প্রতিষ্ঠানের লোগো, সবুজ ব্র্যান্ড হেডার, ৪-কলাম টেবিল এবং লাল রঙে স্পষ্ট বকেয়া প্রদর্শন।
- **৮০ মিমি POS থার্মাল রসিদ:** যেকোনো ব্লুটুথ বা ক্যাশ কাউন্টার থার্মাল প্রিন্টারে প্রিন্টযোগ্য রসিদ।
- **WhatsApp শেয়ারিং:** এক ক্লিকে রসিদের ছবি বা PDF সরাসরি কাস্টমারের হোয়াটসঅ্যাপে প্রেরণের সুবিধা।

### ২. বাকির খাতা ও তাগাদা (Due Ledger & Collections)

- **ক্রেতাভিত্তিক লেজার:** প্রতিটি ক্রেতার পূর্বের বাকি, সাম্প্রতিক কেনাকাটা ও জমার পূর্ণ হিসাব।
- **বিল বিস্তারিত ও রসিদ সংরক্ষণ:** পুরনো যেকোনো বিলের পূর্ণাঙ্গ রসিদ যেকোনো সময় দেখা ও পুনরায় ডাউনলোড করা যায়।
- **কাস্টমার স্টেটমেন্ট PDF:** ক্রেতার সামগ্রিক লেনদেনের সারসংক্ষেপ A4 PDF ফরম্যাটে প্রস্তুত।

### ৩. ইনভেন্টরি ও ক্রয় ব্যবস্থাপনা (Stock & Purchases)

- **রিয়েল-টাইম স্টক ট্র্যাকিং:** বিক্রির সাথে সাথে স্বয়ংক্রিয় স্টক হ্রাস এবং লো-স্টক সতর্কতা।
- **সাপ্লায়ার ক্রয় চালান:** ক্রয়মূল্য, ব্যাচ ও চালান নম্বরসহ পণ্য মজুত বৃদ্ধি।
- **পণ্য ক্যাটাগরি ও কোডিং:** সুনির্দিষ্ট আইডি ও পরিমাপের একক (কেজি, বস্তা, প্যাকেট ইত্যাদি) ব্যবস্থাপনা।

### ৪. দোকান খরচ ও উত্তোলন (Expenses & Drawings)

- **দৈনিক খরচ এন্ট্রি:** দোকান পরিচালনা, পরিবহন, বিদ্যুৎ বা চা-নাশতার খরচের আলাদা হিসাব।
- **মালিকের ব্যক্তিগত উত্তোলন:** ব্যবসার অপারেটিং খরচ থেকে মালিকের নিজস্ব টাকা তোলার হিসাব সম্পূর্ণ আলাদা রাখা হয়, যাতে প্রকৃত লাভ-ক্ষতিতে গরমিল না হয়।

### ৫. ব্যবসায়িক রিপোর্ট ও লাভ-ক্ষতি (Reports & Analytics)

- **১০টি স্ট্যান্ডার্ড বাণিজ্যিক রিপোর্ট:** বিক্রি, ক্রয়, স্টক তালিকা, বাকি রিপোর্ট, ক্যাশ ফ্লো ইত্যাদি।
- **দৈনিক ও মাসিক লাভ-ক্ষতি:** প্রতিটি পণ্যের ক্রয়মূল্য ও বিক্রয়মূল্যের পার্থক্যের ভিত্তিতে নিখুঁত নিট ও গ্রস লাভ নিরূপণ।
- **অফিসিয়াল A4 ব্লু রিপোর্ট PDF:** মার্জিত নীল হেডার, হালকা নীল সারি, পৃষ্ঠা নম্বর, নোট ও স্বাক্ষর লাইনসহ প্রফেশনাল প্রিন্টযোগ্য PDF।

### ৬. প্রতিষ্ঠানের পরিচিতি ও শাখা ব্যবস্থাপনা (Shop Profile Editor)

- **মালিকের সম্পূর্ণ নিয়ন্ত্রণ:** প্রোফাইল থেকে দোকানের নাম, স্লোগান, যোগাযোগের নম্বর (১ ও ২), ঠিকানা এবং লোগো ছবি পরিবর্তনযোগ্য।
- **তাৎক্ষণিক রূপান্তর:** দোকানের তথ্য বদলানোর সাথে সাথে টপবার, লগইন স্ক্রিন, ক্যাশ মেমো, রিপোর্ট PDF ও WhatsApp টেক্সটে স্বয়ংক্রিয়ভাবে নতুন তথ্য বসে যায়।

### ৭. আধুনিক নিরাপত্তা ও পাসকি (Authentication & Security)

- **ভূমিকাভিত্তিক অনুমতি (RBAC):**
  - **মালিক (Owner):** সব ডেটা, প্রফিট-লস, কর্মী ব্যবস্থাপনা ও সেটিংসের পূর্ণ নিয়ন্ত্রণ।
  - **ব্যবস্থাপক (Manager):** ক্রয়, বিক্রি, খরচ ও স্টক ব্যবস্থাপনার অধিকার (লাভ-ক্ষতির সংবেদনশীল তথ্য গোপন থাকে)।
  - **সেলস ম্যান (Salesman):** শুধুমাত্র বিক্রি, রসিদ তৈরি ও বাকি জমার এন্ট্রি।
  - **ক্রেতা (Customer):** নিজের বাকি দেখা, অর্ডার দেওয়া ও পুরনো রসিদ ডাউনলোডের সুযোগ।
- **বায়োমেট্রিক ও পাসকি লগইন (WebAuthn):** ডিভাইসের নিজস্ব ফিঙ্গারপ্রিন্ট, ফেস আনলক বা স্ক্রিন-লক পিন দিয়ে ১-ট্যাপে দ্রুত লগইন।
- **সহজ ইউজারনেম অথেনটিকেশন:** `admin.name`, `manager.name`, `sales.name` প্রিফিক্সভিত্তিক প্রাতিষ্ঠানিক ইউজারনেম।

### ৮. লাইভ আবহাওয়া ও ঘড়ি টপবার (Smart Topbar)

- স্ক্রল করলেও উপরে ফিক্সড থাকে।
- ঢাকার সময় অনুযায়ী বাংলা অঙ্কে চলমান ঘড়ি ও বার-তারিখ।
- Open-Meteo রিয়েল-টাইম আবহাওয়ার সাথে থিম কালার নিজে থেকেই পরিবর্তিত হয় (রোদ, মেঘলা, বৃষ্টি, রাত)।

## 🚀 লোকাল সেটআপ ও চালানো

### প্রয়োজনীয় পরিবেশ:

- **Node.js** (সংস্করণ 20 বা 22+)
- **npm** (সংস্করণ 10+)

### ইনস্টলেশন ধাপসমূহ:

1. **রিপোজিটরি ক্লোন করুন:**

   ```bash
   git clone https://github.com/ajfrinch-ctrl/ShopLedGer.git
   cd ShopLedGer
   ```

2. **ডিপেন্ডেন্সি ইনস্টল করুন:**

   ```bash
   npm install
   ```

3. **ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```
   ব্রাউজারে খুলুন: `http://localhost:8080` (লোকাল নেটওয়ার্কের যে কোনো মোবাইল ডিভাইস থেকেও আইপি দিয়ে ব্যবহার করা যাবে)।

## 📦 বিল্ড ও ডিপ্লয়মেন্ট

### ১. Vercel ডিপ্লয়মেন্ট (SSR / Production)

```bash
npm run build
```

এটি Nitro প্রিসেট অনুযায়ী `.vercel/output` ডিরেক্টরিতে ফুল-স্ট্যাক সার্ভারলেস আউটপুট তৈরি করে এবং মাইগ্রেশন স্ক্রিপ্ট যাচাই করে।

### ২. GitHub Pages ডিপ্লয়মেন্ট (Static SPA)

```bash
npm run build:pages
```

GitHub Actions-এর মাধ্যমে পুশ করলেই স্বয়ংক্রিয়ভাবে বিল্ড হয়ে পেজেসে ডিপ্লয় হয়। লোকাল প্রিভিউ বা টেস্টের জন্য:

```bash
npm run test:pages   # Playwright ব্রাউজার টেস্ট রান
```

## 🔒 গোপনীয়তা ও ডাটা সুরক্ষা

- **অফলাইন-ফার্স্ট নিরাপত্তা:** সকল হিসাব ব্রাউজারের নিজস্ব IndexedDB / localStorage এবং লোকাল PGLite-এ সংরক্ষিত থাকে। ইন্টারনেটে কোনো সংবেদনশীল তথ্য বাইরে যায় না।
- **পাসকি বায়োমেট্রিক নিরাপত্তা:** ফিঙ্গারপ্রিন্ট বা ফেস ডেটা কখনোই ডিভাইসের বাইরে যায় না; সম্পূর্ণ অথেনটিকেশন অপারেটিং সিস্টেমের ক্রিপ্টোগ্রাফিক চাবির মাধ্যমে সম্পন্ন হয়।
- **রোলভিত্তিক সীমাবদ্ধতা:** সাধারণ কর্মচারী বা ক্রেতা কখনোই দোকানের ক্রয়মূল্য বা মুনাফার তথ্য দেখতে পারেন না।
