# কর্ণফুলী সেলস সেন্টার (ShopLedGer)

[![CI](https://github.com/ajfrinch-ctrl/ShopLedGer/actions/workflows/ci.yml/badge.svg)](https://github.com/ajfrinch-ctrl/ShopLedGer/actions/workflows/ci.yml)

গবাদি পশুর খাদ্য সরবরাহ দোকানের জন্য বাংলা, মোবাইল-ফার্সট বিক্রয় ও হিসাব অ্যাপ —
বিক্রি, বাকি আদায়, ক্রয়, খরচ, স্টক, রিপোর্ট ও রসিদ এক জায়গায়।

**কর্ণফুলী সেলস সেন্টার** — পল্লি বিদ্যুৎ অফিসের পাশে, বুড়া মসজিদ রোড, আমুচিয়া, বোয়ালখালী, চট্টগ্রাম।

## মূল ফিচার

- **বিক্রি ও রসিদ** — দ্রুত বিক্রি এন্ট্রি, প্রতিটি বিলের রসিদ (স্ক্রিনে প্রিভিউ + শেয়ার)।
- **বাকি আদায়** — ক্রেতাভিত্তিক বাকির খাতা, আদায়ের হিসাব ও তাগাদা।
- **ক্রয়, খরচ ও স্টক** — পণ্য/স্টক ব্যবস্থাপনা, ক্রয় এন্ট্রি ও দৈনিক খরচ।
- **রিপোর্ট ও লাভ-ক্ষতি** — বিক্রি/ক্রয়/স্টক/বাকি রিপোর্ট, দৈনিক ও মাসিক লাভ-ক্ষতি।
- **মালিক / সেলস ম্যান / ক্রেতা ভূমিকা** — ভূমিকাভিত্তিক অ্যাক্সেস (ডেমো অ্যাকাউন্ট লগইন পেজে দেখা যায়)।
- **সম্পূর্ণ বাংলা ইউআই**, মোবাইল-ফার্সট ডিজাইন।

## টেক স্ট্যাক

| স্তর | প্রযুক্তি |
|------|-----------|
| ফ্রন্টএন্ড + রাউটিং | React 19 + TanStack Start |
| সার্ভার | Nitro (Vercel প্রিসেট) |
| ডাটাবেজ | এম্ববেডেড PGLite (ডিফল্ট) বা `DATABASE_URL` দিলে পোস্টগ্রেস/Neon |
| স্টাইল | Tailwind CSS v4 |

## চালানো

```bash
npm install
npm run dev        # http://localhost:8080
```

কোনো বাহ্যিক সার্ভিস লাগে না — ডাটাবেজ এম্ববেডেড PGLite-এ চলে।

## বিল্ড ও ডিপ্লয়

```bash
npm run build      # vite build (Vercel/nitro আউটপুট: .vercel/output) + db:migrate
```

- **লাইভ:** Vercel — এই রিপোর GitHub ইন্টিগ্রেশন থেকে অটো-ডিপ্লয়
  (ব্রাঞ্চ পুশ → Preview, `main` → Production)।
- `DATABASE_URL` না থাকলে মাইগ্রেশন স্কিপ হয়; অ্যাপ অন্তর্নিহিত PGLite ফলব্যাকে চলে।

## টেস্ট ও মান যাচাই

```bash
npm test           # ইউনিট টেস্ট (node:test)
npm run typecheck  # TypeScript টাইপ-চেক
npm run lint       # ESLint
```

প্রতিটি পুশ ও পুল-রিকোয়েস্টে [CI ওয়ার্কফ্লো](.github/workflows/ci.yml) এগুলো স্বয়ংক্রিয়ভাবে চালায়।
